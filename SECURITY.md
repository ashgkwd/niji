# Security policy

niji is a static check. It reads your code and model metadata and never sends anything anywhere.

## A leak niji missed

A shape of code that leaks personal data and passes niji is a bug in niji, and most of them are safe to discuss in public as long as the example contains no real personal data. Use the "A leak niji missed" issue template.

## A vulnerability in niji itself

If you find a problem in niji that could harm the apps that run it (for example, a way for a crafted template to make niji execute code or write files), report it privately through GitHub's "Report a vulnerability" button on the Security tab of this repository.

## Supported versions

The latest release receives fixes.
