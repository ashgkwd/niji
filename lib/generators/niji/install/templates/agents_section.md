## Personal data

A screen, mail, alt text or share image shows another person only what the page already prints in plain text for that viewer. The columns that identify a person are listed in `PERSONAL_ATTRIBUTES` on the model, and `bundle exec niji` follows them to every view, mailer, helper, controller and service. Run it before you call a task done. A failing run lists each read nobody has reviewed: fix the leak, or add an entry with a one-sentence reason to `config/pii_exposure.yml`. Load the `niji` skill before triaging findings or writing an entry.
